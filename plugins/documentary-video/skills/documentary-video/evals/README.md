# evals

Graded runs must not open this folder's notes. They read only `SKILL.md`,
`references/` and the input document they are given.

## fixtures/

- `ride-dashboard.md`: a fictional ride-hailing company's quarterly
  operations dashboard. The one topic the skill is built against end to end
  (brief → screenplay → bible → cast → world → shots → film). Abstract
  nouns to resolve (wait time, supply, cancellations), a share to show (11%,
  27% vs 6%), a place contrast (airport rank vs business district), a
  time-of-day shape, and a goal that is a plan, not a result.
- `ride-dashboard/film/`: the pre-production files written from it. The
  check scripts' tests use them as the passing case.
