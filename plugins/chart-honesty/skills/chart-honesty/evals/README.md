# chart-honesty — evals

**For whoever runs the evals, not for the skill.** Nothing here is needed to use
`chart-honesty`, and a graded run must not read this file, any `.KEY.md`, or `evals.json`.
They describe what the fixtures contain, and a run that knows the answer isn't being tested.
Point the run at the fixture and at `SKILL.md` plus `references/`, and nothing else under
`evals/`.

## Fixtures

- `board-pack-q3-2026.pptx` is a 14-slide operating-review board pack with 11 charts, all
  native except one picture. Each chart slide plants one thing: an axis set above zero on a
  column chart, a line chart with a non-zero axis that must **not** be flagged, a combo chart
  with a secondary axis, a 3D column chart, a pie of multi-select survey shares, a title
  whose direction the data contradicts, values with no visible unit (the unit is only in the
  notes), a line across unordered categories, a picture of a chart that looks truncated, a
  column chart that PowerPoint auto-scales above zero, and a clean bar chart with a true rank
  claim. Graded by `board-pack-q3-2026.KEY.md` (evals 1, 4, 5).
- `described-charts.md` has four charts described in chat: a set axis on a column chart of
  rates, a pie with too many slices, a clean line chart, and time on a horizontal bar with the
  axis range left out. Graded by `described-charts.KEY.md` (eval 2).

The deck is generated by a private script. Regenerate it rather than editing the `.pptx`.
Its axis behaviour was checked in PowerPoint itself: the auto-scaled chart renders from a
non-zero minimum, and every other column, bar and area axis renders from 0. The 5/6 rule in
`references/checks.md` was measured the same way (smallest/largest 0.83 → axis from 0;
0.834 → not).

All names, companies and figures are invented. None of the fixtures' figures appear in
`SKILL.md` or `references/`. The references' examples use their own invented numbers, so they
teach the rules, not the answers.
